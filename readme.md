做一个开源工具包，做文本数据的copyright detective，目的在于：帮助用户找到大模型的训练数据中非法使用有版权数据的的证据。
先做一个主要功能：
有选项可以输入api key/model name来选择需要测试的模型（或者自己部署的开源模型也需要考虑）
再做以下两个功能：
1.用户分别输入两个文本，分别为（如带版权书籍的）上下段。prompt让llm根据上一段生成下一段，并与用户输入的真实的下一段进行比较rouge分数，得到答案。
2.用户输入一个pdf，切割成长度适中的若干段，相邻两段为上下段，分成多组，也跟第一个功能一样，prompt让llm根据上一段生成下一段，并与用户输入的真实的下一段进行比较rouge分数，得到答案。最终挑出来生成rouge分比较高的上下文
